# Eagle Driving Mantra — website

Driving school website for Eagle Driving Mantra, Hobart, Tasmania (founded 2018).

## Preview on GitHub Pages
1. Upload every file and the `assets` folder to the root of a GitHub repository.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
3. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Going live on the real domain
- Point `eaglemantra.com.au` at the host and update nothing else: canonical URLs, sitemap and structured data already use that domain.
- `_headers` adds security headers on Netlify or Cloudflare Pages (GitHub Pages ignores it; the in-page security policy still applies).
- Submit `sitemap.xml` in Google Search Console and add the site link to the Google Business Profile.
